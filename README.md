# SWT MindFlow 身心智慧學院（主畫面原型）

## 上架 GitHub Pages
1. 把這個資料夾裡的 **全部檔案** 上傳到 repository 根目錄，保持結構：
   ```
   index.html
   scenes/main.jpg  scenes/gate.jpg  scenes/mind.jpg  scenes/mentor.jpg
   scenes/chess.jpg scenes/life.jpg  scenes/hallin.jpg
   ```
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 等 1～2 分鐘，開啟 `https://<帳號>.github.io/<repository 名稱>/`。

## 注意
- 不要直接用雙擊 `index.html` 開啟（file://），瀏覽器會擋住場景圖，請用 GitHub Pages 或本機伺服器測試。
- 檔名大小寫要一致（GitHub Pages 區分大小寫），`scenes` 資料夾不能改名。
- 更新後若看到舊畫面，按 Ctrl+F5（Mac：Cmd+Shift+R）強制重新整理。
